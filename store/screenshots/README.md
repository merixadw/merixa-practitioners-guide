# Screenshots (binaries not committed)

Place App Store PNGs here after Mac Simulator / device capture.
See `../SCREENSHOTS.md` for sizes, scenes, and naming.

```
store/screenshots/
  6.7/   # 1290×2796 — iPhone 6.7"
  6.1/   # 1179×2556 — iPhone 6.1"
```

PNG files are gitignored (`*` in this folder). Keep this README and the size
folder placeholders in git so the path is obvious on Windows clones.

**Cannot capture on Windows** — Device Lab is UI preview only, not ASC-valid.
